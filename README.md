#### 🎮 [chifoumi-arbitre](https://github.com/diopttt678-lab/chifoumi-arbitre)

A rock-paper-scissors referee you play with your hand through the webcam — MediaPipe Hands → gesture classification → a cheating computer opponent.

The detail I'm proudest of: catching that `cv2.waitKey(1800)` for the cheat popup was **blocking the entire game loop** for 1.8 seconds. It's drawn frame-by-frame now, and 5 tests cover the rules and the gesture logic without a webcam.
